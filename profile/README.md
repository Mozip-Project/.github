# MOZIP.

**공고부터 결과 발표까지, 모집의 모든 과정을 한곳에서**

동아리 · 학회 · 학생회 모집을 지원자와 운영진이 한곳에서 끝내는 통합 모집 플랫폼

</div>

<br />

## Why MOZIP.

모집 과정은 공고 · 지원 · 평가 · 면접 · 결과 안내가 서로 다른 채널과 도구에 흩어져 있습니다.
지원자는 공고를 찾고 지원 현황을 관리하는 데, 운영진은 지원서를 옮기고 평가를 취합하는 데 시간을 씁니다.
MOZIP.은 이 흐름을 하나로 잇습니다.

<br />

## Features

| 지원자 | 운영진 |
| --- | --- |
| 조건별 공고 탐색 · 스크랩 | 단계별 공고 작성 · 게시 |
| 서비스 안에서 간편 지원 | 서류 평가자 설정 · 평가 취합 |
| 지원 현황 · 결과 한눈에 확인 | 면접 타임테이블 자동 생성 |
| 프로필 · 면접 일정 관리 | 합격 · 불합격 결과 일괄 안내 |
